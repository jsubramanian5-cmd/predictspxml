# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Auditable SPX settlement quantile forecasts (p10/p50/p90) for two horizons: weekly (SPXW PM, settles to the close) and monthly (SET AM, opening-based). Python package `spx_forecast` (`src/spx_forecast/`) plus a Windows WPF viewer (`src/ForecastViewer/`, .NET 10) that reads the forecast CSVs and hosts the iron-condor estimate and paper-trade journal. `AGENTS.md` has general repo guidelines; `README.md`, `VALIDATION.md` and `docs/live_forecast.md` hold the detailed rationale.

## Commands

Windows / PowerShell, Python 3.13 (the lock targets Windows x64). Use the repo venv:

```powershell
.\.venv\Scripts\python -m pip install -r requirements.lock
.\.venv\Scripts\python -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python -m pytest -q                              # all tests
.\.venv\Scripts\python -m pytest tests/test_live.py -q           # one file
.\.venv\Scripts\python -m pytest tests/test_core.py -k name -q   # one test
.\.venv\Scripts\python scripts/start_jupyter.py                  # use this launcher, not bare jupyter (--check to inspect)
$env:PYTHONPATH = "src"; python -m scripts.run_live_forecast     # daily live run (--skip-refresh --now <ISO> to replay)
.\.venv\Scripts\python -m scripts.build_contract_import          # regenerate contracts after a new settlement archive
.\.venv\Scripts\python scripts/build_calendar_import.py          # regenerate calendar from reviewed Cboe docs
.\.venv\Scripts\python scripts/build_notebook.py                 # regenerate notebooks/spx_forecast.ipynb (it is generated)
```

No linter/formatter is configured. Viewer: `dotnet build src/ForecastViewer` (bin/obj are gitignored).

## Architecture

- **Notebook is the research interface** (`notebooks/spx_forecast.ipynb`, generated by `scripts/build_notebook.py` via nbformat — edit the script, not the notebook). A single config cell controls dates, paths, refresh, seed. Pipeline logic lives in `src/spx_forecast/`: `ingestion`/`refresh` (FRED, Cboe, content-addressed raw snapshots in `data/raw/`), `calendar`/`upcoming` (pinned official calendar and contract schedule), `features`, `models`/`backtest` (expanding-window refits, development vs. frozen final-test), `forecast`, `workflow.prepare`, `live`, `plots`.
- **Live path** (`scripts/run_live_forecast.py`, order matters): refresh price imports (merge only, never rewrite history) → rebuild `upcoming_contracts` → `workflow.prepare` with `live_cboe_spx=True` → forecast once using models chosen by the last backtest (`artifacts/run_metadata.json`; the live run never re-tunes). Exit codes: 0 ok, 1 error, 2 refresh failure/reconciliation diff/calendar runway <60 days, 3 missed issue window.
- **Data flow**: `data/imports/` (manual/merged source CSVs, byte-preserved by `.gitattributes`) → `data/normalized/*.parquet` → `artifacts/` (forecast/status CSVs, backtests, scorecards). Source data, results and models are intentionally committed for cross-machine continuation; routine daily runs therefore show many modified data/artifact files.
- **Output contract**: `artifacts/latest_forecast.csv` and `artifacts/daily/forecast_YYYY-MM-DD.csv` are consumed downstream (the viewer and an external iron-condor strategy). Schema is append-only: never rename, reorder or remove columns; bump `schema_version` when adding.

## Invariants to preserve

- Never overwrite an already-issued forecast or its `issued_at`; reruns must be idempotent. Pending runs emit schemas/statuses, never fabricated forecasts.
- Settlement labels are official Cboe settlements, never substituted with SPX closes (only exception: weekly SPXW PM `cboe_close_proxy` in the live scorecard). Synthetic data exists only in tests.
- Inputs count as available when the pipeline first sees them; publication window is reference-session 20:00 ET to next-session 08:00 ET. Backtest labels use FRED SPX; live reference closes may come from Cboe SPX_History (recorded in `reference_close_source`).
- Model selection freezes before final testing; ML only replaces the benchmark if it wins on the paired final-test interval score with coverage at least as close to 80%.
- Model pickles in `artifacts/models/` are trusted-local only.
- Run one notebook/forecast writer at a time.
- The pinned calendar ends 2026-12-31; the 2027 Cboe calendar must be imported and reviewed (`docs/calendar_review.json`, `docs/imports.md`) before then.
